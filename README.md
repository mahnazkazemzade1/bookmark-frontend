BookMark
BookMark is a personal front-end project where I built an online bookstore website using HTML, CSS, and JavaScript.
I wanted to create a clean and easy-to-use design that makes browsing books feel simple and enjoyable. While working on this project, I focused on the layout, colors, styling, and small details that make a website look and feel better.

### Built With
- HTML5
- CSS3
- JavaScript

Running the Project
Download or clone the repository, open the project folder in VS Code, and run `index.html` in your browser. You can also use the Live Server extension.
About
This project is part of my journey in front-end development. I'm using it to improve my coding skills, experiment with UI design, and build projects that I can share in my portfolio.
